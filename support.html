TwinBoy

TwinBoy support

TwinBoy plays .gb and .gbc game files on your device. Tobu Tobu Girl is included, so you can start playing right away.

Add a game

Open Menu, Game library, then the plus button. Choose a game file in Files. You can also open a compatible file in TwinBoy from another app. Use game files you have the right to use. ZIP archives must be extracted first.

Save and resume

Games with cartridge saving save their progress automatically. For a snapshot at any point, open Menu and tap Save beside one of the three slots. Tap Load to return to that snapshot. Saving to an occupied slot replaces its previous snapshot.

Removing a game from the library keeps its saves. Import the same game file again to use them. Deleting TwinBoy removes its local games, saves and settings unless restored from a device backup.

Controls

Use the D-pad to move, A and B to play, and Start to begin. X and Y repeat A and B while held. Menu, Settings includes button layouts, shell colors, screen palettes, sharp or smooth pixels, sound and fast-forward speed. The D-pad is always on the right. Supported game controllers and keyboards also work.

A game will not open

Check that the file is an extracted .gb or .gbc file. TwinBoy does not support games for other consoles. Try the included game to check that the app is working. Some cartridge hardware may not be supported.

No sound

Turn on Sound in Menu, Settings and check your device volume and audio output. Fast forward deliberately mutes game audio.
